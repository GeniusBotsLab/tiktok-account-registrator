# Security policy

## Public repository boundary

Do not submit or publish credentials, cookies, access tokens, session exports, phone numbers, account exports, browser profiles, proxy credentials, customer data, logs, or private source code.

## Reporting

Report security concerns privately via [@TheBotsLab](https://t.me/TheBotsLab) or [BotsLab@proton.me](mailto:BotsLab@proton.me). Do not open a public issue containing sensitive information.
