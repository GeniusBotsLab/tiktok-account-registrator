# TikTok workspace — content operations

Управляемые браузерные процессы для своих TikTok-аккаунтов: контент, комментарии, статусы и отчётность.

TikTok workspace не связан с TikTok или ByteDance и не является их официальным продуктом. Публичная документация описывает browser automation на базе ZennoPoster, служебные профили, очереди, публикацию собственного контента, разбор входящих комментариев и журналы рабочего процесса.

Клиент владеет аккаунтом или имеет письменное право его администрировать. Граница работы — только свои данные и авторизованные аккаунты. Нет обхода антифрода, спама, накрутки, обхода ограничений или доступа к чужим учётным записям.

Этот репозиторий — публичная документация без production-кода, cookies, токенов, прокси, клиентских баз и внутренних профилей.
